# 底盘控制结构

`application/chassis_task.c` 只负责初始化、控制周期和调用次序。内部模块接收已初始化的非空底盘状态，周期参数以秒为单位；不在每个私有函数重复检查指针。

## 一个周期

```text
采集与估计 → 模式迁移 → 普通目标 → 起立/跳跃覆盖 → 攀爬覆盖
          → 起立/自救目标 → PID/LQR + 前馈 → 起立覆盖/混合 → VMC映射 → 电机发送
```

周期使用实际 RTOS tick 间隔。电机发送中原有的等待和末尾任务延时保留，不能把末尾的 2 ms 延时当作实际控制周期。

在线调参量由使用它的模块持有：跟随参数在 `chassis_motion.c`，PID、姿态、LQR和质心前馈参数在 `chassis_control.c`。原有使用中的标量名与独立 ELF section 保留。

## LQR 状态与力矩分量

正常落地平衡默认使用完整的 4×10 反馈，`tune_lqr_cross_leg_scale=1.0`，补入此前被屏蔽的对侧腿角、角速度反馈；设为 0 可对比旧行为。起跳/离地等特殊工况仍沿用原权重选择和输出覆盖。拟合增益表、姿态参考、前馈和输出限幅未因这次补项而重新标定。

`chassis_balance.h` 的 `LQR_X_*` 给出十列状态名；`chassis_control.c` 用具名下标填写“目标 - 测量”的误差。四行输出明确命名如下，均为模型坐标下的 N·m：

| K 的行（从 0 开始） | `chassis_lqr_feedback` 字段 | 对应输出 |
| --- | --- | --- |
| 0 | `left_wheel` | 左轮驱动力矩 |
| 1 | `right_wheel` | 右轮驱动力矩，后续保留原有右轮镜像 |
| 2 | `left_leg` | 左虚拟腿摆动力矩，经 VMC 分配到关节电机 1/2 |
| 3 | `right_leg` | 右虚拟腿摆动力矩，经 VMC 分配到关节电机 4/3 |

每个输出中，`position_nm` / `speed_nm` 是位置/速度误差的力矩贡献，`yaw_nm` / `yaw_rate_nm` 是航向贡献，`left_leg_angle_nm` / `left_leg_rate_nm` 和 `right_leg_angle_nm` / `right_leg_rate_nm` 是左右腿贡献，`body_pitch_nm` / `body_pitch_rate_nm` 是机身俯仰贡献。例如 `chassis_lqr_feedback.left_wheel.right_leg_angle_nm` 就是右腿角度误差对左轮力矩的贡献，已经乘入对侧腿权重。

`motion_nm` 为位置、速度、yaw、yaw 角速度四项之和；`balance_nm` 为左右腿和机身 pitch 的六项之和；`total_nm` 为两者相加。控制模块仍分别对接原移动/平衡力矩通道；这些诊断值在前馈、限幅和特殊工况覆盖之前，不能当作最终电机力矩。虚拟腿摆动力矩还需与腿长支撑力共同经 VMC 映射，不能直接当作某台关节电机的命令。

已通过编译源码的矩阵乘法对照检查和两板固件构建；尚未烧录或验证补项后的实车稳定性。

## 停车与云台跟随

- 松杆后立即用零速目标和有界的位置参考共同制动：从当前点建立参考，锁定前参考与实际位置的误差不超过 `0.06 m`，不再在高速滑行时完全随车更新而使位置反馈一直为零。融合速度绝对值不超过 `0.10 m/s` 持续 `150 ms` 后，捕获此时的位置并固定；中途超过速度门限重新计时，不因超时在高速滑行中强制锁定。原 `0.06 m/s` 是捕获位置门限，原逻辑在门限外仍有零速 LQR 制动；本次同时放宽捕获条件和补充锁定前的位置约束。
- 静止和移动时均可跟随云台，不再要求平移速度超过启动门限。A/D 保留左右行进方向的角度偏置，松开后恢复朝向云台；死区内的平移指令不产生方向偏置。手动转向/自旋指令优先，松开后先减速再恢复自动跟随。
- 自动跟随采用“云台角差 P + 云台绝对转速前馈 → 限速/加减速 → LQR 的 yaw 角速度目标”。前馈由连续底盘 yaw 增量与编码器相对角增量相加后经 `40 ms` 滤波得到，使用 `0.5` 倍；不微分 A/D 方向偏置或对齐零点，手动转向及松杆制动时清零前馈。默认 P 保持 `0.08 (rad/s)/deg`，限速保持 `1.5 rad/s`，加速保持 `4.5 rad/s²`，减速为其 `2` 倍。角差滤波缩短至 `20 ms`，回正或反向时立即收回较大的旧角差。保留 `1°/0.4°` 启停滞回，连续转动的云台需同时满足估计转速低于 `0.04 rad/s` 才退出跟随。
- 云台每拍发送已有 `auto_flag`：自瞄开启即禁止底盘自动跟随，不依赖是否识别到目标。底盘撤销自动 yaw 速度及其前馈，捕获航向保持；手动转向及其松杆制动仍可用。退出自瞄重新建立速度估计基准，并按原加速度限制恢复跟随。负载/帧长度及字段偏移均未改变，两板构建检查 `auto_flag` 仍位于偏移 38。
- 转向期间 yaw 角度目标等于实测连续航向，不叠加角度超前或积分角度增量；转速指令归零后捕获航向，由原 LQR 保持。制动包络约束角差修正的相对速度，前馈与修正相加后仍受总转速限制。这些是指令侧约束，不能视为已标定实车停车距离。

## 精简后的约定

- 数值检查留在KF、观测输入和实际限幅边界，私有函数不重复做空指针检查。
- KF无可信轮速时直接返回无效，不再额外预测100 ms，也不自动重新播种。
- IMU/KF无效而落地轮速仍新鲜时，观测模块回退轮速；两者都不可用时暂停积分，位置锁释放，LQR平移误差置零。
- 接地和攀爬模块只报告状态。离地控制与收腿输出屏蔽统一在控制模块执行，防止后续前馈重新叠加。
- 跳跃准备原本恒为真的占位函数已移除，保留原本直接进入伸腿的行为。
- 攀爬中未使用的电流、速度差和腿角基准计算已移除。
- 起立/自救先按目标腿长分支：两腿都短则直接 LQR；任意一条长则角向后摆（径向零指令力）、快速收腿、渐进接 LQR。不要求摆腿先抬起机身，目标腿长采用当前操作高度。
- 攀爬撞阶确认后，同周期停止前进并进入平滑收腿，不再经过越阶等待和顶面姿态确认。`CLIMB_PULL_UP` 及后续状态编号保留，便于对照历史波形；撞阶参数、收腿时长和异常中止仍采用当前配置。
- 收腿的双腿到位确认（`10 ms`）与 `300 ms` 收腿轨迹并行，二者完成后直接进入 `CLIMB_STAND_UP`，恢复平衡控制；取消收腿和旧轮子确认阶段串行等待俯仰角速度稳定的流程。旧 `CLIMB_WHEEL_CONFIRM` 编号保留，正常流程不再进入。起立从最后的收腿目标开始，保持腿长目标连续，且必须完成 `500 ms` 起立轨迹后才开始站稳确认，避免 `6 cm` 高度容差使其提前结束。姿态异常中止、收腿未到位超时和再次按 F 平滑退出仍保留；该衔接条件不等于直接测到了轮子接触台阶顶面。

## 2026-11-10 控制优化

本次没有上板运行或烧录，下面的参数是待实车验证的初值，不能据主机回归声称姿态抖动已消除。

### roll 与腿长目标

`chassis_control.c` 单独计算 roll PID，不改共用 PID，避免影响云台和腿长环。P=220、Ki=0.08、积分限幅=2.5、总输出限幅=10 保持；积分按 `dt/0.004` 换算，保留在线 `tune_roll_ki` 的原调参含义。D 从角度误差的每拍差分，改为 `-Kd*roll_gyro`，默认 Kd=1.0 N/(rad/s)，因此新旧 Kd 的数值不能直接比较。

PID 输出饱和时禁止继续同向积累；上一周期任一关节达到输出限幅时停止增加积分，允许已有积分回退。起立、离地、跳跃、攀爬、自救、失能或周期/roll 数据异常时清理 roll PID。几何 roll 补偿保留原方向，但对称限制左右腿目标在 0.17–0.34 m 内。没有仅凭“稍歪后回正”就放大积分限幅；实际原因仍需同时看 roll、角速度、Iout、左右腿长和电机饱和情况。

### 2026-11-16 氮气弹簧安装后的起立/自救

启动/恢复请求先读取目标腿长 `clamp(high_set, 0.17, 0.34)`：两腿实测长度均不长于目标（含相等）时，直接进入 `BALANCING_READY`，由正常 LQR 起立；不再强制摆腿、收腿或要求腿角到位。任一腿仍长于目标时，才走后摆、收腿和 LQR 渐进交接。后摆期间如果两腿都变短，也可直接进入正常平衡。

| 阶段 | 执行内容 | 进入下一阶段 |
| --- | --- | --- |
| 启动/恢复入口 | 比较左右实际腿长与 `high_set` | 两腿都短/相等直接 LQR；单侧或双侧长进入 `REC_SWING` |
| `REC_WAIT` | MIT 零力矩卸力，等待恢复键新按下沿 | 再按恢复键后重新按腿长选择分支 |
| `REC_SWING` | 只控制角向运动，两腿保持用户确认的转向，向约 1.3 rad 后摆；已经在 1.0～1.35 rad 后方范围的腿直接记为到位，先到者保持实际到位角。径向指令力为零，不运行腿长 PID | 两腿均变短可直接 LQR；否则双侧到位标志均锁存后立即收腿，不再要求同一拍同时处于窄角窗，不等角速度稳定或机身抬起 |
| `REC_RETRACT` | 各腿从实际长度收向 `min(自身起始长度, high_set)`，保持进入收腿时各自实际角度；径向指令仅允许收缩或零，不继承摆腿积分推力 | 轨迹结束且两腿均不长于目标加 3 cm，持续 150 ms；更短的腿不阻碍交接，没有腿角到位门槛 |
| `REC_BLEND` | 保留收腿结束时的控制输出，角度参考转成对地坐标，渐进交给正常控制 | 2 s 后进入 `BALANCING_READY` |
| `REC_IDLE` | 正常 LQR/运动控制 | 原有跌倒监测及恢复请求逻辑 |

转向保持用户确认“现在这版不反”的 `STARTUP_SWING_DIRECTION=-1`，本轮没有翻转方向。左右统一模型角分别为 `leg_angle_local` 和 `-leg_angle_local`，角速度同样镜像右腿，不叠加 pitch；未到位时两腿角速度目标同方向。到位后退出摆腿速度积分，使用总限幅 ±4 N*m 的 PD 保持实际到位角；小范围保持纠偏允许双向力矩，但不会再选择反向整圈摆腿。检测相邻采样是否沿指定方向跨过后方入口，避免跳过角窗漏记。旧双关节速度驱动中，左电机 1/2 负、右电机 3/4 正；现在经 VMC 转成角向力矩，右侧镜像仍只做一次。实际实物视角依用户确认及后续实车核对，不从代码符号单独断言。

后摆时真正释放径向控制：两关节各自锁速度也会间接锁定开合角/腿长，因此恢复动作不再使用该速度模式。任务初始化时先请求 MIT，后摆由统一局部角速度 PI（Kp=8 N*m/(rad/s)、Ki=6 N*m/rad，虚拟角向力矩限幅 8 N*m）生成角向力矩，经 VMC 用 `[F=0,T]` 分配。不会把 `leg_length_set` 或当前长腿长度当作后摆腿长闭环目标，氮气弹簧和机械机构承担被动径向作用。这里的零指令力不等于不存在弹簧力、摩擦或地面接触力。

进入收腿时清除左右腿长 PID，`recovery.force_bias_L/R=0`、`torque_bias_L/R=0`。此前把速度积分固定加到收腿角度 PD 上，会使大积分始终推向原方向，甚至无法被 ±4 N*m 的 PD 纠偏抵消；现已移除该固定偏置，收腿角向输出仅为总限幅 ±4 N*m 的实际角度保持 PD。腿长 PID 输出限制在 `[-max_out,0]`，不积累正向积分；短腿或向内超调时不会主动撑长。所有角向/径向输出最终仍受每台电机 8 N*m 和 20 N*m/s 约束，LQR 交接期间按比例恢复原正常限幅；没有直接增大单电机输出上限。

收腿最大参考速度保持 0.30 m/s，最短时间 0.3 s，三次曲线始末速度为零。时长为 `max(0.3,1.5*最大单腿距离/0.30)`；缩短 10 cm 约 0.5 s、20 cm 约 1 s。这是轨迹时间，实际完成仍取决于执行器跟踪和 150 ms 到位确认。`high_set` 是目标腿长，不是另设一个固定起立高度；本轮保留当前用户的普通腿长 PID 参数和配平值。

约 1.3 rad 是后摆到位位置，收腿时分别保持各腿的 `start_angle_L/R`，不强迫已经在后方的腿回追同一个标称角。机身 pitch/角速度不参与该 PD 的误差和阻尼。进入 LQR 交接后，各腿使用 `leg_angle_set=(1-alpha)*(自身起始角+pitch-实际配平角)` 转成原有对地角坐标，并连续移回实际配平角；已短腿的长度参考也从自身收腿终点渐进恢复到正常目标高度。两腿都短时的直接 LQR 分支则立即使用正常站立角参考和目标腿长。正常控制原有跌倒监测、交接时大倾角退出、卡滞停止和阶段超时保留。

`recovery.length_error_L/R` 是共同目标减实测腿长；`angle_error_L/R` 是各腿起始保持角减统一局部腿角，仅供观察。`start_angle_L/R` 是收腿保持角，`target_angle` 保留标称 1.3 rad 供观察；正常观测/LQR 的 `leg_angle/leg_gyro` 仍为对地坐标。`recovery.retract_blockers` 的位值为 1=轨迹未结束、2=左腿仍偏长、4=右腿仍偏长，进入等待时保留、下一次后摆清零。没有角度等待位。未到位时的角向 PI 积分可在 `recovery.swing_L/R.rate_integral_nm` 观察，到位后清零。

调度保持 `RecoveryUpdate -> ControlCalculate -> RecoveryApply -> ControlMap`，每拍只做一次映射。摆腿、收腿及 LQR 均发送 MIT 力矩协议，摆腿中 `swing_velocity_active=0`、关节 `velocity_native=0`，不再通过原生速度环约束径向腿长。遗留原生速度映射代码保留，但本恢复动作不启用。遥控失能仍发送 MIT 零力矩卸力。

### 静止时的速度 KF

保留 `[v, 加速度等效零偏]` 模型，预测输入仍为去重力前向 IMU 加速度，轮速为量测。普通过程噪声强度 Qacc=0.04、零偏过程噪声强度 Qbias=1e-5、轮速方差 R=0.02 保持。

`chassis_observer.c` 在双轮落地、正常平衡、无平移/转向请求、轮速/机身角速度/摆腿速度及校正后加速度均较小时连续确认 200 ms，再使用 Qacc=0.01、R=0.04。收到运动请求、检测到加速度或角速度变化、反馈失效时当拍退出静止滤波。没有将速度硬置零，也没有增添零速伪量测。主机注入的交替轮速噪声检查显示输出均方值降低；这不等于实车抖动的量化结果。

目前没有把轮毂力矩替换成主速度 KF 的预测输入。这样做需同时考虑腿角、髋力矩、惯量、打滑和电流标定，直接以 `tau/(m*r)` 替换会把模型误差带入平衡反馈；本次仅在碰撞判据中使用这种近似，不接管主平衡估计。

### 碰撞/持续顶推后退离

新增 `chassis_collision.c/.h`，在普通运动目标后、停车和 yaw 目标前运行，保留 LQR 平衡执行。使用**反馈轮电流**估算驱动力，而非未经限幅的 LQR 请求。总质量初值 15.05 kg 来自工程已有模型。近似纵向扰动为 `F_ext = m*a_forward - (i_R-i_L)/(2598.20*r)`，通过 40 ms 一阶滤波。它包含摩擦、腿部及质心运动等模型误差，不能当作精确接触力传感器。

| 阶段/判据 | 当前实现 |
| --- | --- |
| 检测条件 | 普通落地平衡；新鲜有效的融合估计；无手动旋转；排除跳跃、攀爬、自救和较大姿态/腿部运动；先确认有效条件 300 ms |
| 持续顶推 | 速度目标绝对值 >0.2 m/s，实测速度 <0.08 m/s，反向扰动 >18 N，持续 350 ms |
| 碰撞 | 使用未滤波扰动，绝对值 >35 N、前向加速度绝对值 >1.8 m/s² 且同号；连续同号至少 8 ms，并且扰动除以质量的积分绝对值达到 0.04 m/s。脉冲结束或方向改变时重置；不等待 40 ms 力滤波，静止时受撞也可触发 |
| 冲击退让 | 确认冲击后当拍释放旧停车参考、记录航向，直接进入退让；已沿退让方向移动时从当前速度建立参考并限幅，不再等待车速降至 0.08 m/s |
| 顶推制动 | 持续顶推触发时撤销原前进目标和停车位置锁，记录航向；至少等待 120 ms 且速度 <0.08 m/s 才退离，600 ms 未稳则停车保持 |
| 退离 | 朝扰动力方向远离接触面；速度目标按 0.5 m/s² 上升至 0.18 m/s，保持触发时航向，禁止云台自动跟随 |
| 结束 | 退离里程达 0.20 m，或退离阶段达到 1.8 s；也在再次遇反向阻力、向错误方向位移 >0.05 m 或估计失效时停车 |
| 重置 | 停车保持时原移动指令需回到死区 200 ms；持续按原方向不会自动再撞入，也不会无限重试；失能/特殊动作/手动旋转优先并退出退离 |

可通过 `chassis_collision` 查看状态、有效位、原始/滤波扰动、持续时间、`impact_delta_v_m_s` 和事件数；`chassis_odometry.stationary_filter` 可确认静止滤波是否生效。退离距离使用轮速里程，存在轮胎打滑误差；当前只能估计前后方向的异常阻力，不能可靠区分侧向接触、斜坡和所有模型误差，也不能确认退离方向没有其他障碍。它是有限退离逻辑，没有地图导航或绕行规划。碰撞门限、质量及电流到轮端力矩比例必须通过受约束的低速实车数据验证。
