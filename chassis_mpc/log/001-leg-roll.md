# 001 腿长与 roll 调试

调试日期：2026-10-15。记录整理：2026-10-16。

## 现象与目的

用户反馈偶发上下起伏，前进/后退时腿长有时忽高忽低，怀疑积分项不合适。先小幅调整积分增益和限幅，观察变化。

## 改动

| 项目 | 试调与当前编译值 | 位置 |
| --- | --- | --- |
| 腿长 Ki | 0.08 → 0.075；P=300、D=300 | `src/application/chassis_tuning.h` |
| 腿长积分限幅 | 当前 2.5；PID 输出限幅 50 | 同上 |
| roll PID | 当前 P=300、I=0.08、D=10；积分限幅 2.5、输出限幅 10 | 同上 |
| 在线积分参数 | `tune_leg_ki`、`tune_leg_i_limit`、`tune_roll_ki`、`tune_roll_i_limit` | `src/application/chassis_tuning.c` |
| 参数应用 | 每周期验证范围，更新左右腿/roll PID，并收回超出新限幅的积分输出 | `chassis_tuning_apply()` |
| roll 支撑分配 | 左腿 `+PID.out`、右腿 `-PID.out`，避免两侧同时减支撑 | `Chassis_Torque_Calculation()` |

当时的试调约束为 Ki 在 0—0.1，积分限幅在 0—3；非有限或超范围请求不应用。后续已在 [005 简化记录](005-control-simplification.md) 中放宽临时门槛。Ki 是现有 PID 每次调用的参数，没有将 PID 改为按 dt 积分。

## 实测与限制

- 腿长 Ki 从 0.08 降至 0.075 后，用户反馈“差不多，仍偶发起伏”。
- roll 调整后，用户仍反馈前进/后退过程中腿长变化。
- 没有证据证明积分项是唯一原因，也没有将腿长起伏记录为已修复。
- 实测任务周期与旧的固定腿部微分时间可能不一致，接触判定、运动耦合仍需单独核对。

## 后续

保持其他环节不变时，结合腿长目标/反馈、支撑力、积分输出和接地状态比较，避免只凭机身外观继续增加 I。
