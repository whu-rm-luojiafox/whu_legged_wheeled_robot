# 五连杆雅可比、左右视图与上交 WBR 坐标系核对

核对日期：2026-09-09。依据当前 `application/chassis_task.c`、`chassis_task.h`、`05LQR/HerKules_VOCAL_SJ_LQR_v4_with_data_WHU_3.m`，以及本机上交原文 `WBR_leg.html`、`WBR_modeling.html`。

实物已确认：**从每台髋关节电机自身的轴侧看，编码器、速度和力矩的正方向均为逆时针。** 左右外侧视图与“电机轴侧视图”不一定是同一观察方向；判断电机指令正负时，以各自轴侧为唯一基准。

本次已修改控制固件中的坐标混用、偏导公式、求逆转置和右腿关节顺序。上车前仍应在悬空、限流条件下逐个验证电机编号及正力矩方向。

## 1. 三种角度不能混用

- `a_i`：电机 `position`，经过软件零点偏置后的电机角，函数入口单位为度。正值表示从该电机轴侧看逆时针。
- `Q0=atan2(xc,yc)`：五连杆正解内部的机身局部腿角，相对机身向下轴。
- `theta_l`：上交 WBR 系统模型使用的腿对自然坐标系竖直方向倾角。

上交 `WBR_leg` 式 (6.1)：

```text
theta_l = theta + theta_b
```

其中 `theta` 是相对机身的腿角，`theta_b` 是机身 pitch。因此：

```text
左腿：theta_l,L = +Q0,L + pitch
右腿：theta_l,R = -Q0,R + pitch
```

五连杆雅可比必须使用 `Q0`，LQR 必须使用 `theta_l`。代码现在分别保存：

| 字段 | 含义 | 使用者 |
|---|---|---|
| `leg_angle_local` | 原始局部 `Q0` | 五连杆雅可比 |
| `leg_angle` | 统一方向后再加 pitch 的 `theta_l` | WBR/LQR |
| `leg_length_raw` | 当前未滤波几何长度 | 五连杆雅可比 |
| `leg_length` | 滤波后的控制状态 | 腿长控制、LQR 拟合 |

这里“对地角”指相对重力竖直方向，不是相对斜坡法线。

## 2. 左视图和右视图

观察者位于机器人对应一侧的外面，头朝上。图中局部轴随机身一起俯仰。

```text
左外侧视图：车头 ←                      右外侧视图：车头 →

前髋 1 (A)─── O ───(E) 2 后髋          后髋 4 (A)─── O ───(E) 3 前髋
              │ → +xL（车后）                         │ → +xR（车前）
              ↓ +yL                                  ↓ +yR
              C 轮轴                                  C 轮轴

局部 Q0,L 正：向纸面右偏                  局部 Q0,R 正：向纸面右偏
统一 theta_L 正：腿向车前倾               统一 theta_R 正：腿向车前倾（=-Q0,R）
```

上交模型的统一物理定义是：`theta_l>0` 表示髋部相对轮轴向车前倾。左右腿同样前倾时，送入 LQR 的两个腿角必须同号。

图中纸面的顺/逆时针只描述机构坐标。**电机正方向不从左右外视图推断**：1、2、3、4 号电机都从各自轴侧看，逆时针为正；从电机非轴侧观察时，视觉方向必然反转。

## 3. N11、N12、N21、N22 的定义

当前单腿正解定义：

```text
phi1 = pi + a_first
phi2 = pi - a_second
B = (-L5/2 + L1*cos(phi1), L1*sin(phi1))
D = (+L5/2 - L4*cos(phi2), L4*sin(phi2))
C = (l*sin(Q0), l*cos(Q0))
```

`a_first/a_second` 换算成弧度后参与计算。当前调用顺序：

| 腿 | first | second |
|---|---:|---:|
| 左腿 | 电机 1 | 电机 2 |
| 右腿 | 电机 4 | 电机 3 |

上交第 4 节的矩阵是逆运动学雅可比：

```text
N = J^-1 = [ dphi1/dl   dphi1/dQ0 ] = [ N11 N12 ]
           [ dphi2/dl   dphi2/dQ0 ]   [ N21 N22 ]
```

所以 N 的行表示一条腿的两根主动杆，列表示腿长和局部腿角；N11 等下标不表示左右腿。

N 对几何角 `phi` 求导。按当前正解：

```text
dphi1 = +da_first
dphi2 = -da_second
```

这两个符号是几何参数与电机坐标之间的映射。电机坐标自身的正方向已经统一为“轴侧看逆时针”。

## 4. 正确的四个偏导

令：

```text
u = xc-xb = xe+X1       v = yc-yb = ye-Y1
r = xc-xd = xe-X2       s = yc-yd = ye-Y2
xe = l*sin(Q0)           ye = l*cos(Q0)
```

则：

```text
D1 = L1 * (-u*sin(phi1) + v*cos(phi1))
D2 = L4 * ( r*sin(phi2) + s*cos(phi2))

N11 =     (u*sin(Q0) + v*cos(Q0)) / D1
N12 = l * (u*cos(Q0) - v*sin(Q0)) / D1
N21 =     (r*sin(Q0) + s*cos(Q0)) / D2
N22 = l * (r*cos(Q0) - s*sin(Q0)) / D2
```

推导来自两条从动杆约束 `|C-B|²=L2²`、`|C-D|²=L3²` 的全微分，与上交式 (4.4)～(4.7) 一致。固件中的 `get_jacobian_element()` 已按这些式子修改。

## 5. N 必须先求逆再转置

上交式 (4.1)、(4.8)、(5.1)：

```text
phidot = N * [ldot,Q0dot]^T
J = inverse(N)
tau_phi = J^T * [F,Tlocal]^T = N^(-T) * [F,Tlocal]^T
```

不能直接用 `N*[F,T]`。令：

```text
S   = diag(1,-1)       // phi 到 first/second 电机角
H_L = diag(1,+1)       // theta_L=+Q0,L
H_R = diag(1,-1)       // theta_R=-Q0,R
```

从上交模型虚拟力 `[F,Tmodel]` 到轴侧逆时针为正的电机力矩：

```text
tau_motor = S * inverse(N)^T * H_side * [F,Tmodel]^T
```

若 `detN=N11*N22-N12*N21`，固件使用的展开式为：

```text
左腿：
tau1 = (N22*F_L - N21*T_L)/detN_L
tau2 = (N12*F_L - N11*T_L)/detN_L

右腿：
tau4 = (N22*F_R + N21*T_R)/detN_R
tau3 = (N12*F_R + N11*T_R)/detN_R
```

这里输出正值的唯一物理含义是：从相应电机轴侧看产生逆时针力矩。右腿正解的第一、第二关节是 4、3 号，因此输出也必须按 4、3 路由。旧代码把第一组送给电机 3，已经更正。

右腿 LQR 产生的 `T_R` 现在保持上交统一腿角的符号，镜像变换只在 `H_R` 中做一次。旧代码在 LQR 输出处先取负、映射处再散落加负号，已经删除这些重复变换。右轮轮毂电机自身的方向处理不属于本次髋关节雅可比修改。

当 `|detN|<=1e-6` 时，固件将该腿两个关节力矩置零，防止奇异位形产生 NaN 或过大输出。

## 6. 电机零点

必须区别几何角零点和电机软件零点：

| 零点 | 主动杆方向 |
|---|---|
| `phi1=0` | 第一主动杆从 A 指向另一髋轴 E |
| `phi2=0` | 第二主动杆从 E 指向另一髋轴 A |
| `a_first=0,a_second=0` | `phi1=phi2=pi`，两主动杆各自朝外水平 |

按当前编号：1、3 号软件零对应主动杆朝车前；2、4 号软件零对应主动杆朝车后。方向相对机身髋轴连线，机身倾斜时一起转动。

`LEG_OFFSET=30°`。初始化记录当前编码器为 `position_offset`，随后设置：

```text
a1=a4=+30°
a2=a3=-30°
```

代入正解得到 `phi1=phi2=210°`，腿处于较短的上限位附近。该做法隐含要求：采集 offset 时机械必须位于规定的标定/上限位姿态。任意姿态上电后直接采集编码器值，无法自动获得正确几何零点。

## 7. 数值验证

运行：

```powershell
python docs/jacobian_coordinate_check.py
```

脚本使用当前连杆参数，在 256 个非奇异姿态上比较解析雅可比与正解中心差分：

```text
最大正解偏导误差                 4.558e-10
最大 N*J_fd-diag(1,-1) 残差     1.618e-09
修正后固件 N 与解析 N 最大误差   2.665e-15
展开力矩式与矩阵式最大误差       4.441e-15
左右腿最大虚功/功率残差          1.776e-15
```

这验证了几何偏导、求逆转置以及左右腿符号矩阵。实车验证仍需悬空限流进行：分别给每台电机小正力矩，确认从该电机轴侧看均为逆时针，同时核对 1/2/4/3 的正解输入顺序。

上交 `WBR_modeling` 中 A/B 的“偏导”是系统加速度对状态和输入的线性化偏导；本文件的 N 是五连杆运动学偏导。两者通过 `theta_l` 状态和虚拟腿力矩连接，含义不同。
